# Лабораторная работа № 1 — Генетический алгоритм

**Дисциплина:** «Эволюционное программирование и генетические алгоритмы»  
**Вариант:** 8  
**Язык программирования:** Python 3

## Цель работы

Реализовать генетический алгоритм для непрерывной многомерной оптимизации, исследовать влияние размера популяции и сравнить результаты с базовым случайным поиском при одинаковом бюджете вычислений целевой функции.

## Постановка задачи

Минимизируется функция Захарова:

\[
f(x)=\sum_{i=1}^{d}x_i^2+
\left(\sum_{i=1}^{d}0.5 i x_i\right)^2+
\left(\sum_{i=1}^{d}0.5 i x_i\right)^4.
\]

Для варианта 8 используется размерность \(d=7\) и область поиска

\[
x_i \in [-5,10], \quad i=1,\ldots,7.
\]

Теоретический глобальный минимум функции равен \(0\) и достигается в точке \(x=(0,\ldots,0)\).

## Реализация генетического алгоритма

Одна особь представляется вектором из семи вещественных координат. Качество решения оценивается значением функции Захарова: чем меньше значение, тем лучше решение.

В программе самостоятельно реализованы следующие компоненты:

- **Инициализация:** равномерная генерация начальной популяции в допустимой области.
- **Селекция:** турнирный отбор из трёх случайных особей.
- **Кроссовер:** арифметический кроссовер с вероятностью `0.9`.
- **Мутация:** гауссовское возмущение координат; вероятность мутации одной координаты равна \(1/d\), стандартное отклонение — `0.5`.
- **Обработка ограничений:** координаты после мутации ограничиваются диапазоном `[-5, 10]`.
- **Элитизм:** лучшая особь переносится в следующее поколение вместе с уже вычисленным значением целевой функции.

Готовые оптимизаторы не используются.

## Эксперимент

Сравниваются три метода:

| Название | Метод | Размер популяции |
|---|---|---:|
| `GA_50` | Генетический алгоритм | 50 |
| `GA_100` | Генетический алгоритм | 100 |
| `Random` | Равномерный случайный поиск | — |

Для каждого метода выполнено 20 независимых запусков. Использованы начальные значения генератора случайных чисел (`seed`) от `42` до `61`. Бюджет каждого запуска — **10 000 фактических вычислений целевой функции**. Между двумя конфигурациями генетического алгоритма изменяется только размер популяции.

### Результаты

Статистика итогового значения целевой функции по 20 запускам:

| Алгоритм | Минимум | Среднее | Медиана | Стандартное отклонение | Максимум |
|---|---:|---:|---:|---:|---:|
| `GA_50` | 0.0000622 | 0.0004019 | 0.0003471 | 0.0002366 | 0.0008194 |
| `GA_100` | 0.0006302 | 0.0040661 | 0.0028721 | 0.0030782 | 0.0117266 |
| `Random` | 4.825923 | 15.921965 | 15.695334 | 5.771831 | 25.253844 |

Лучший результат в этой серии получен `GA_50`, запуск № 19:

\[
f(x) \approx 6.2187 \cdot 10^{-5}.
\]

Найденный вектор решения:

```text
[0.00542121, 0.00126568, 0.00254429, 0.00368848,
 0.00018113, -0.00216525, -0.00231996]
```

### Интерпретация

В проведённом эксперименте обе конфигурации генетического алгоритма существенно превзошли случайный поиск. Вариант с популяцией 50 особей показал лучшие итоговые показатели, чем вариант с популяцией 100 особей, при выбранных параметрах и фиксированном бюджете. Этот результат относится к данной серии запусков и не означает, что меньшая популяция всегда эффективнее.

## Установка и запуск

Требуется Python 3. Установите зависимости:

```bash
python -m pip install numpy pandas matplotlib
```

Запустите эксперимент из каталога проекта:

```bash
python main.py --runs 20 --budget 10000 --seed 42
```

Параметры командной строки:

- `--runs` — число запусков; для воспроизведения эксперимента используется `20`;
- `--budget` — число вычислений целевой функции на каждый запуск; используется `10000`;
- `--seed` — начальное значение генератора случайных чисел; используется `42`.

После выполнения программа создаёт или обновляет `results.csv`, `summary.csv` и `convergence.png`.

## Вывод

Реализован генетический алгоритм для минимизации функции Захарова в семимерном пространстве. Проведено сравнение двух размеров популяции и случайного поиска по 20 запускам при одинаковом бюджете в 10 000 вычислений целевой функции. В данной серии экспериментов генетический алгоритм приблизился к теоретическому минимуму и показал существенно лучшие результаты, чем случайный поиск.
